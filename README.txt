HEAVENS HAIR & BEAUTY — GITHUB PAGES WEBSITE

This folder contains the complete single-page homepage demo. Every project file is together in this one folder; there is no assets subfolder.

FILES
- index.html                  Homepage (keep this at the repository root)
- styles.css                  Design, responsive layout and animations
- script.js                   Mobile navigation, scroll effects and FAQ interactions
- heavens-salon-sign.jpg     Salon signboard photo
- .nojekyll                   GitHub Pages helper file

PREVIEW
Open index.html in a modern browser. The site uses relative paths for all local files, including the salon signboard image.

PUBLISH WITH GITHUB PAGES
1. Create a new GitHub repository (for example: heavens-salon-website).
2. Upload the CONTENTS of this folder to the repository's main/root directory. Do not upload the ZIP itself or create another subfolder in the repository.
3. In the repository, open Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the main branch and /(root), then Save.
6. After GitHub Pages finishes publishing, copy the website URL shown in Settings → Pages and share that URL with the salon.

NOTES BEFORE SHARING
- This is a homepage concept/demo, not an approved final salon website.
- Editorial salon photographs and Google Fonts are loaded from external services (Unsplash and Google Fonts), so an internet connection is needed for those external items.
- The salon signboard photo is included in this same folder as index.html.
- Confirm the salon's address, phone numbers, WhatsApp availability, service list and opening hours with the owner before launch.
- Replace sample inspiration photos with salon-approved photos before the final public launch.
- The contact links currently use the phone numbers that appear readable on the supplied signboard; verify them with the owner.
